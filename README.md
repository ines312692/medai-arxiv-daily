## How it works

`scripts/update.py` queries the [arXiv API](https://info.arxiv.org/help/api/), tags each paper with keyword rules from `config.json`, and writes the digests. A scheduled GitHub Actions workflow runs it daily. No dependencies beyond the Python standard library.
